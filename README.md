# NetXScan

Desktop app foundation (Module 1): Electron Forge + Vite + React + TypeScript + Tailwind.

Requires Node.js. This repo includes `.nvmrc` for [nvm](https://github.com/nvm-sh/nvm) / [nvm-windows](https://github.com/coreybutler/nvm-windows).

```bash
nvm use 24.6.0
npm install
npm start
```

(`nvm-windows` requires the version argument; it matches `.nvmrc`.)
